# Demon Hunters — Website

Static React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion site.
<!-- 
## Run locally

```
npm install
npm run dev
```

## Build for production

```
npm run build
```

The output goes to `dist/` — deploy that folder to any static host
(Netlify, Vercel, GitHub Pages, S3, etc).

## Structure

```
src/
  components/   one folder per section (Navbar, Hero, Stats, About, ...)
  data/         content.ts — all copy/data, separate from UI
  pages/        Home.tsx composes the sections
  assets/       demon-hunters-logo.png
```

Colors, type scale and shared background system live in `src/index.css`
under the `@theme` block, and in `AnimatedBackground`/`Reveal`/`SectionHeading`
in `src/components/shared` and `src/components/AnimatedBackground`. -->
